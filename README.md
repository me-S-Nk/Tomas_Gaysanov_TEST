# Tomas Gaysanov

A personal portfolio and media website for **Tomas Gaysanov**, bringing together his projects, public presence, media activity, and collaboration opportunities in one digital space.

**Tomas Gaysanov** is a personal web project designed as a digital home for Tomas's work, projects, public appearances, and professional connections.

The website combines a minimal editorial aesthetic with interactive navigation and visual storytelling.

* 👤 Personal presentation
* 🚀 Projects and initiatives

* 🤝 Collaboration opportunities

## 🎨 Design

The website follows a **minimal editorial / personal-brand aesthetic** with a strong focus on typography, large visual elements, and structured navigation.

The interface uses custom SVG icons, dedicated visual assets, and separate stylesheets for different sections of the website.

## ⚡ Running Locally

The project is a static website, so it does not require a backend or database to run locally.

### Option 1 — Open directly

Open:

```text
index.html
```

in a browser.

### Option 2 — Use a local server

For example, with Python:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
